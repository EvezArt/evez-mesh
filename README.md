# EVEZ Mesh — Decentralized Brain Network

Unfogger + brokerage mesh for distributed AI cognition across EVEZ services.

## Quick Start

```bash
git clone https://github.com/EvezArt/evez-mesh.git
cd evez-mesh
pip install -r requirements.txt
python mesh.py
```

## Architecture
- Mesh Brain (:8893) — distributed inference coordinator
- Mesh Broker (:8894) — message routing and event distribution
- Unfogger — clarity extraction from noisy data
- Brokerage — trust-weighted decision routing
